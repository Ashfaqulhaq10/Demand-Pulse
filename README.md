# 🚀 DemandPulse: Next-Gen AI Travel Forecasting

DemandPulse is a premium, AI-powered travel demand forecasting system designed to provide hyper-accurate, location-aware predictions. Combining advanced Machine Learning with the latest Generative AI, DemandPulse helps users stay ahead of travel surges.

---

## ✨ Key Features

### 🤖 **Gemini AI Integration**
- **Powered by Gemini 2.5 Flash**: A state-of-the-art conversational assistant integrated directly into the dashboard.
- **Context-Aware Assistance**: Get instant help with demand trends, travel advice, and platform navigation.
- **Premium UX**: Glassmorphic chat interface with smooth animations and real-time status indicators.

### 🧠 **Predictive Intelligence**
- **FD-SSR Algorithm**: Custom-built forecasting logic for precise demand pressure analysis.
- **Location-Aware**: Dynamic city-specific demand profiles and holiday detection.
- **5-Day Forecast**: Visualized projections to help plan trips days in advance.

### 🌦️ **Real-Time Environmental Data**
- **Weather Integration**: Live weather data fetched via Open-Meteo & OpenWeatherMap APIs.
- **Impact Analysis**: Automatically adjusts demand scores based on severe weather conditions.

### 🎨 **Visual Excellence**
- **3D Immersive Design**: Interactive Three.js background for a professional, forward-thinking feel.
- **Data Visualization**: High-performance charts powered by Recharts for clear technical insights.

## 🚀 Getting Started

### Backend Setup
1. Navigate to the root folder:
   ```bash
   pip install -r requirements.txt
   python backend_api.py
   ```
2. API will be live at `http://localhost:8000`

### Frontend Setup
1. Navigate to the `DemandPulse` directory:
   ```bash
   npm install
   npm run dev
   ```
2. Access the dashboard at `http://localhost:5173`
